# 집계산기

부동산 계산기 모음. 서버·DB·로그인 없이 브라우저에서만 계산하며 입력값을 저장하지 않습니다.

## 실행

`index.html`을 브라우저로 열거나 `python3 -m http.server 8080` 실행 후 http://localhost:8080 접속.

## 사이트 빌드

헤더·메뉴·푸터·메타 태그는 모든 페이지에 같은 틀로 들어갑니다. 페이지를 추가하거나 메뉴를 바꿀 때는
`tools/build/` 의 등록부를 고치고 `python3 tools/build/build.py` 를 실행해 다시 생성합니다. 자세한 내용은 `tools/build/README.md` 를 보세요.

## 재방문 기능

- **최근 계산 기억** — 각 계산기의 스위치를 켜면 입력값을 브라우저 로컬 스토리지에만 저장. 끄면 즉시 삭제. 기본 꺼짐
- **공유하기** — 기기 공유창(카카오톡 등)으로 결과 요약과 링크 전송. 미지원 브라우저는 복사로 대체
- **링크 복사** — 입력값을 URL 쿼리에 담은 링크 복사
- **이미지 저장** — 결과 카드를 PNG로 내려받기. 외부 라이브러리 없이 캔버스로 그림
- **테마 전환** — 헤더 버튼으로 밝게·어둡게 수동 전환. 선택은 로컬 스토리지에 저장
- **홈 화면 추가** — `manifest.json`과 `sw.js`. 정적 자산은 캐시 우선, HTML은 네트워크 우선

## 방문 통계

`js/analytics.js`의 `GA_ID` 또는 `NAVER_ID`에 측정 ID를 넣기 전까지는 아무것도 로드하지 않습니다.
ID를 넣으면 `privacy.html` 6-1 항목을 실제 도입 내용으로 갱신하세요.

## 구조

- `css/site.css` — 공통 스타일. 색·간격은 `:root` 변수로 관리하며 다크 모드 대응
- `js/common.js` — 숫자 파싱·포맷, 금액 입력 콤마, 토스트, 공유 링크, 내비
- `js/<계산기>.js` — 페이지별 계산 로직 11개. 공통 배선은 `Site.wireCalc`가 담당
- `js/analytics.js` — 방문 통계 로더 (ID 비어 있으면 동작 안 함)
- `sw.js`, `manifest.json` — 앱 설치와 오프라인 캐시
- `tools/build/` — 사이트 빌더

기본 금리, 프리셋 값, 중개보수 요율표 등 바뀔 수 있는 값은 각 스크립트 상단에 상수로 모아두었습니다.

## 계산 공식

**월세 실부담**
- 월고정 = 월세 + 관리비 + 기타월고정
- 보증금월기회비용 = 보증금 × (연금리% ÷ 12 ÷ 100)
- 실부담월 = 월고정 + 보증금월기회비용, 실부담연 = 실부담월 × 12
- 전세→월세상당 = 전세보증금 × (전세연금리% ÷ 12 ÷ 100)
- 월세→필요전세금 = max(0, (실부담월 − 관리비 − 기타) ÷ (전세연금리% ÷ 12 ÷ 100)), 분모 0이면 미표시

**대출이자**
- 원리금균등 월납 = P × r × (1+r)^n ÷ ((1+r)^n − 1), r = 연금리 ÷ 12 ÷ 100
- 원금균등 = 매월 원금 P÷n + 잔액 × r
- 만기일시 = 매월 P × r, 만기에 원금 일시 상환
- 거치기간 중에는 이자만 납부하며 원금 상환은 거치 후 회차부터

**상가 수익률**
- 연 순영업수익 = 월세 × 12 − 공실 차감 − 연 운영비
- 실투자금 = 매매가 + 취득 부대비용 − 임대 보증금
- 총투자 수익률 = 순영업수익 ÷ 실투자금
- 자기자본 수익률 = (순영업수익 − 연 대출이자) ÷ (실투자금 − 대출금액)

**중개보수**
- 주택: 거래금액 구간별 상한 요율과 한도액 적용
- 월세 거래금액 = 보증금 + 월세 × 100, 환산액이 5천만원 미만이면 보증금 + 월세 × 70
- 주거용 오피스텔 매매 0.5% / 임대차 0.4%, 그 외 0.9% 이내 협의
- 부가세 10%는 선택 표시

## 공통 기능

- 입력 즉시 재계산. CTA 버튼은 재계산 후 결과로 스크롤
- 금액 입력 천단위 콤마, 금리·기간 0·빈값·음수 가드
- 예시 프리셋 버튼, 결과 링크 복사(입력값을 URL 쿼리에만 담음), 모바일 하단 요약 바
- 한글 UI, 접근 가능한 라벨, 반응형, 다크 모드

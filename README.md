# 월세 실부담 계산기 (MVP)

월세·관리비·기타 고정비에 보증금 기회비용을 더해 "진짜 매달 나가는 돈"을 계산하고, 전세 월세 환산 비교표를 보여주는 한 페이지 웹앱입니다. 서버·DB·로그인 없이 브라우저에서만 계산하며 입력값을 저장하지 않습니다.

## 실행

`index.html`을 브라우저로 열거나 `python3 -m http.server 8080` 실행 후 http://localhost:8080 접속.

## 구성

- `index.html` — 마크업 (입력 폼, 결과, 전월세 환산표, 제휴/광고 슬롯, 면책)
- `styles.css` — 모바일 우선 반응형 스타일 (다크 모드 대응)
- `app.js` — 계산 로직·입력 포맷·토스트. 기본 금리 등 상수는 파일 상단에 모여 있음

## 계산 공식

- 월고정 = 월세 + 관리비 + 기타월고정
- 보증금월기회비용 = 보증금 × (연금리% ÷ 12 ÷ 100)
- 실부담월 = 월고정 + 보증금월기회비용
- 실부담연 = 실부담월 × 12
- 전세→월세상당 = 전세보증금 × (전세연금리% ÷ 12 ÷ 100)
- 월세→필요전세금 = max(0, (실부담월 − 관리비 − 기타월고정) ÷ (전세연금리% ÷ 12 ÷ 100)), 분모 0이면 표시 안 함

입력이 바뀌면 즉시 재계산되며, "실부담 계산하기" 버튼은 재계산 후 결과로 스크롤합니다.

본 계산기는 참고용이며 금융·세무·법률 자문이 아닙니다.

## 배포 (GitHub Pages)

`.github/workflows/pages.yml`이 `main`에 푸시될 때마다 GitHub Pages로 배포합니다. 처음 한 번은 저장소 **Settings → Pages**에서 Source를 `GitHub Actions`로 설정해야 합니다.
